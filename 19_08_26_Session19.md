## 1. Processing Structured Datasets

In practical board examinations, data is rarely represented as a flat list of items. Instead, it is structured as:
1. **List of Tuples:** A dataset representing relational database rows.
2. **List of Dictionaries:** A dataset representing JSON objects or key-value structures.

You must be comfortable iterating over these datasets, checking conditions on specific elements/keys, and pushing either a single field (like a name string) or the whole record (the tuple/dictionary) onto the stack.

### Case A: Pushing Specific Fields (List of Tuples)
```python
# Record format: (roll_no, name, score)
students = [
    (1, "Aanya", 92),
    (2, "Kabir", 65),
    (3, "Dia", 85)
]

def push_distinction_names(student_list, stack):
    for roll, name, score in student_list:
        # Check condition on index 2 (score)
        if score >= 75:
            # Push ONLY index 1 (name string)
            stack.append(name)
```

### Case B: Pushing Whole Records (List of Dictionaries)
```python
# Record format: dict with keys "item", "qty", "price"
inventory = [
    {"item": "Notebook", "qty": 15},
    {"item": "Pen", "qty": 85},
    {"item": "Marker", "qty": 5}
]

def push_low_stock_records(inventory_list, stack):
    for product in inventory_list:
        # Check key "qty"
        if product["qty"] < 20:
            # Push the ENTIRE dictionary record
            stack.append(product)
```

## 2. Displaying Stack Contents Vertically

In a stack, elements are added and removed from the **Top** (the end of the list). To visually display a stack, we should show it vertically with the top element at the top of our output.

We implement this by calculating the top index (`len(stack) - 1`) and looping backwards down to index `0` with a negative step of `-1`.

```python
def display_stack(stack):
    if len(stack) == 0:
        print("Stack is empty.")
    else:
        top_idx = len(stack) - 1
        # Print top element with label
        print(f"{stack[top_idx]} <-- TOP")
        # Loop backwards through the rest
        for i in range(top_idx - 1, -1, -1):
            print(stack[i])
```

If the stack is `["Pen", "Pencil", "Eraser"]`, the output of `display_stack` is:
```
Eraser <-- TOP
Pencil
Pen
```

## 3. The For-Loop Pop Trap (Modifying Lists During Iteration)

When emptying a stack, you might be tempted to use a `for-in` loop over the stack. **This is a logical trap!**

```python
# ❌ BUGGY CODE
stk = ["A", "B", "C", "D"]
for item in stk:
    print("Popped:", stk.pop())
```

### Why does this fail?
As the loop runs, Python increments its internal index. But calling `.pop()` shrinks the list dynamically. The loop index and list length meet in the middle, causing the loop to terminate after only two iterations!
* **Output:**
  ```
  Popped: D
  Popped: C
  ```
* **Remaining Stack State:** `["A", "B"]` (The first two elements were never popped!).

### The Correct Way
Always use a **`while`** loop that checks stack length dynamically:
```python
# ✅ CORRECT CODE
stk = ["A", "B", "C", "D"]
while len(stk) > 0:
    print("Popped:", stk.pop())
```
* **Output:**
  ```
  Popped: D
  Popped: C
  Popped: B
  Popped: A
  ```
* **Remaining Stack State:** `[]` (Completely empty).
