## 1. What is a CSV File?

**CSV** stands for **Comma-Separated Values**. It is a plain text file format used to store tabular data (numbers and text) in spreadsheet format.
- Each line in a CSV file corresponds to a **data record (row)**.
- Each record consists of one or more fields, separated by **commas (delimiters)**.

### Why Use Python's `csv` Module Instead of Plain Text `.split(',')`?
If a field contains a comma inside quotes (e.g. `"12, MG Road, Chennai"`), plain text `.split(',')` splits it into multiple false columns!  
Python's built-in `csv` module automatically handles quotes, commas within text, line breaks, and standard tabular formatting.

## 2. Writing CSV Files (`csv.writer`)

To write to a CSV file, we import the `csv` module and use `csv.writer()`.

### 🚨 The `newline=''` Rule (MANDATORY)
When opening a CSV file for writing or appending in Python, **always pass `newline=''`** to `open()`.
```python
with open("students.csv", "w", newline="") as f:
    # ...
```
**Why?** Without `newline=''`, Python and the `csv` module both add line terminators (`\r\n`), causing blank empty lines between every row on disk!

### Writing Single vs Batch Rows

```python
import csv

# Data lists
header = ["Roll", "Name", "Marks"]
rows = [
    [101, "Mahissh", 95],
    [102, "Aditya", 88],
    [103, "Rohan", 92]
]

with open("students.csv", "w", newline="") as f:
    writer = csv.writer(f)
    
    # 1. writeone row at a time (1D list)
    writer.writerow(header)
    
    # 2. writerows writes multiple rows at once (2D list of lists)
    writer.writerows(rows)
```

## 3. Reading CSV Files (`csv.reader`)

To read records from a CSV file, use `csv.reader()`. It returns an iterable object where each item is a **list of strings**.

```python
import csv

with open("students.csv", "r") as f:
    reader = csv.reader(f)
    
    # Skip header row if present
    header = next(reader)
    print("Header columns:", header)
    
    for row in reader:
        # row is a list of strings: ['101', 'Mahissh', '95']
        roll = row[0]
        name = row[1]
        marks = int(row[2])  # MUST convert string to integer!
        
        if marks >= 90:
            print(f"Top Student: {name} ({marks})")
```

> [!IMPORTANT]
> **Type Casting Rule:** Everything returned by `csv.reader()` is of type `str`. If you need to perform calculations or numerical comparisons (`>`, `<`, `+`), you **must explicitly convert** the field using `int(row[i])` or `float(row[i])`.

## 4. Modern CSV: `csv.DictReader` and `csv.DictWriter`

Instead of remembering column index numbers (`row[0]`, `row[1]`), `DictReader` and `DictWriter` allow you to access values using header field names!

### Reading with `DictReader`
```python
import csv

with open("students.csv", "r") as f:
    reader = csv.DictReader(f)
    for row in reader:
        # row is a dictionary: {'Roll': '101', 'Name': 'Mahissh', 'Marks': '95'}
        print(f"{row['Name']} scored {row['Marks']}")
```

### Writing with `DictWriter`
```python
import csv

fields = ["UserID", "Password", "Status"]
data = [
    {"UserID": "user1", "Password": "pass123", "Status": "Active"},
    {"UserID": "user2", "Password": "secret456", "Status": "Pending"}
]

with open("users.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=fields)
    writer.writeheader()  # Writes the header row: UserID,Password,Status
    writer.writerows(data)
```

## 5. Handling Custom Delimiters (Pipe / TSV)

If a file uses a character other than a comma (such as a pipe `|` or tab `\t`), pass the `delimiter` argument:

```python
import csv

# Reading pipe-separated values
with open("data.psv", "r") as f:
    reader = csv.reader(f, delimiter="|")
    for row in reader:
        print(row)
```

## 6. CBSE Board Exam Standard Template: User Credential Search

```python
import csv

def search_user_password(target_user):
    found = False
    with open("user_credentials.csv", "r") as f:
        reader = csv.reader(f)
        header = next(reader)  # Skip header
        
        for row in reader:
            if len(row) >= 2 and row[0] == target_user:
                print(f"Password for '{target_user}': {row[1]}")
                found = True
                break
                
    if not found:
        print("User ID not found in database.")
```
