## 1. Why Can't We Update Binary Files in Place?

In text files, we sometimes overwrite character-by-character. In **Binary Files**, this is highly dangerous and practically forbidden for two reasons:
1. **Variable Byte Sizes:** Pickled Python objects are represented as variable-length byte blocks. If you change a dictionary's value (e.g. changing marks from `80` to `100`), the new pickled object might take 65 bytes instead of the original 60 bytes. Overwriting in-place will overwrite (and corrupt) the start of the next record!
2. **Immediate Truncation:** Opening a file in write mode (`'wb'`) wipes all existing records immediately.

Thus, to update or delete records, we must use one of the two strategies described below.

---

## 2. Strategy A: The In-Memory Method (Read-Modify-Write)

This method is ideal for smaller data files that easily fit in memory.

### Workflow:
1. Open the file in `'rb'` mode and load all records into a Python list.
2. Iterate through the list in memory and modify or remove the target record.
3. Open the same file in `'wb'` mode (wiping it) and dump all records from the list back to the file.

```python
import pickle

def update_marks_in_memory(roll, new_marks):
    records = []
    # Step 1: Read all records
    with open("student.dat", "rb") as f:
        try:
            while True:
                records.append(pickle.load(f))
        except EOFError:
            pass
            
    # Step 2: Modify in memory
    for r in records:
        if r["roll"] == roll:
            r["marks"] = new_marks
            
    # Step 3: Rewrite file
    with open("student.dat", "wb") as f:
        for r in records:
            pickle.dump(r, f)
```

## 3. Strategy B: The Temporary File Method (Standard CBSE Boilerplate)

This method is highly efficient because it processes records as a stream, keeping only one record in memory at a time. It is the standard method tested on CBSE exams.

### Workflow:
1. Open the source file `student.dat` in read-binary (`'rb'`) mode.
2. Open a temporary file `temp.dat` in write-binary (`'wb'`) mode.
3. In a loop, load each record from the source file.
4. **For Updates:** If it matches the target, modify it and write it to `temp.dat`. Otherwise, write it as-is.
5. **For Deletions:** If it matches the target, skip writing it (use `continue`). Otherwise, write it to `temp.dat`.
6. Close both files (exit the `with` block).
7. Delete the original file: `os.remove("student.dat")`.
8. Rename the temporary file: `os.rename("temp.dat", "student.dat")`.

```python
import pickle
import os  # MANDATORY for file deletion and renaming

def delete_record_temp_file(roll_to_delete):
    with open("student.dat", "rb") as fin, open("temp.dat", "wb") as fout:
        try:
            while True:
                rec = pickle.load(fin)
                if rec["roll"] == roll_to_delete:
                    # Skip writing this record to delete it!
                    continue
                pickle.dump(rec, fout)
        except EOFError:
            pass
            
    # Context blocks ended - files are closed! Safe to remove/rename.
    os.remove("student.dat")
    os.rename("temp.dat", "student.dat")
```

## 4. 🚨 Important OS Exceptions & Traps

### A. The Windows File Lock Exception
If you try to run `os.remove()` or `os.rename()` while the file stream is still open inside the context manager, Windows will raise a `PermissionError`.
* **Fix:** Always write your OS commands **outside** the `with` block, ensuring the file objects are closed and unlocked first.

```python
# ❌ INCORRECT (CRASHES ON WINDOWS)
with open("data.dat", "rb") as fin, open("temp.dat", "wb") as fout:
    # ... read/write ...
    os.remove("data.dat")  # CRASH! File is still open.

# ✅ CORRECT
with open("data.dat", "rb") as fin, open("temp.dat", "wb") as fout:
    # ... read/write ...
# Files closed here
os.remove("data.dat")  # Safe execution
```

### B. Missing `import os`
The commands `os.remove()` and `os.rename()` belong to Python's standard `os` module. Do not forget to write `import os` at the top of your program!
