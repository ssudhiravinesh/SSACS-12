## 1. Writing Data: `write()` vs `writelines()`

To write data to text files in Python, we use either `write()` or `writelines()`.

### A. The `write()` Method
* **Signature:** `file_object.write(string)`
* Writes a **single string** to the file.
* It does **not** append a newline (`\n`) automatically. You must add it manually.
* Returns: Number of characters written.

```python
with open("output.txt", "w") as f:
    f.write("Hello World\n")  # Must add \n manually
    f.write("Python is fun.")
```

### B. The `writelines()` Method
* **Signature:** `file_object.writelines(iterable_of_strings)`
* Writes a **list (or any iterable)** of strings to the file.
* 🚨 **Common Misconception:** Many students think `writelines()` writes each string on a new line. **It does not!** It writes them back-to-back. You must include `\n` in the strings.

```python
# THIS WRITES: AlphaBetaGamma (all in one line!)
lines_bad = ["Alpha", "Beta", "Gamma"]
with open("test.txt", "w") as f:
    f.writelines(lines_bad)

# THIS WRITES on separate lines:
lines_good = ["Alpha\n", "Beta\n", "Gamma\n"]
with open("test.txt", "w") as f:
    f.writelines(lines_good)
```

## 2. File Pointers: `tell()` and `seek()`

Every open file has an internal cursor or pointer that tracks the current read/write location (measured in **bytes**).

```
File contents:   P   y   t   h   o   n
Byte indexes:    0   1   2   3   4   5   6 (EOF)
                 ▲
           Initial Pointer (index 0)
```

### A. The `tell()` Method
* **Syntax:** `file_object.tell()`
* Returns the current cursor position as an integer (byte offset from the start).

### B. The `seek()` Method
* **Syntax:** `file_object.seek(offset, whence=0)`
* Repositions the file pointer.
  * `offset`: Number of bytes to move (positive = forward, negative = backward).
  * `whence`: Reference position:
    * `0` (Default): Start of the file.
    * `1`: Current cursor position.
    * `2`: End of the file.

---

## 3. 🚨 The Python 3 Text-Mode Seek Restriction

> [!IMPORTANT]
> In Python 3, if a file is opened in text mode (`'r'`, `'w'`, `'a'`, `'r+'`), **non-zero offsets are ONLY allowed relative to the start of the file (`whence=0`)**.
> Any attempt to use `seek(offset, 1)` or `seek(offset, 2)` with a non-zero offset will crash the program!

```python
with open("sample.txt", "r") as f:
    f.read(4)
    # THIS WILL CRASH:
    f.seek(2, 1)  # Raises: UnsupportedOperation: can't do nonzero cur-relative seeks
    
    # THIS IS ALLOWED (Absolute seek from start):
    f.seek(6, 0)  # Moves to absolute byte index 6
```

* **How to bypass this:** If you need relative seeks (e.g., jumping back 5 bytes from the end), you must open the file in **binary mode** (`"rb"`, `"wb"`, etc.), which does not translate characters and allows full pointer movements.

## 4. Key Text File Processing Algorithms (CBSE Checklist)

### Pattern 1: Target Word Counter (e.g., counting word `"the"`)
```python
def count_the_word(filename):
    count = 0
    with open(filename, "r") as f:
        for line in f:
            words = line.split()  # Splits line into words by whitespace
            for w in words:
                # Strip punctuation (like 'the.' or 'the,')
                cleaned = w.strip(".,!?;:()\"'").lower()
                if cleaned == "the":
                    count += 1
    return count
```

### Pattern 2: Character Category Counter
```python
def count_chars(filename):
    vowels = 0
    consonants = 0
    uppercase = 0
    lowercase = 0
    
    with open(filename, "r") as f:
        content = f.read()
        for ch in content:
            if ch.isupper():
                uppercase += 1
            elif ch.islower():
                lowercase += 1
                
            if ch.lower() in "aeiou":
                vowels += 1
            elif ch.isalpha():
                consonants += 1
                
    print(f"Upper: {uppercase} | Lower: {lowercase}")
    print(f"Vowels: {vowels} | Consonants: {consonants}")
```

### Pattern 3: Line Filtering & In-place Modification
To remove lines matching a criteria from the same file, you must read all content into memory, filter it, and rewrite the file:
```python
def remove_empty_lines(filename):
    # Step 1: Read all lines
    filtered = []
    with open(filename, "r") as f:
        for line in f:
            if line.strip():  # If the line is not just whitespace
                filtered.append(line)
                
    # Step 2: Overwrite the file with the filtered lines
    with open(filename, "w") as f:
        f.writelines(filtered)
```
