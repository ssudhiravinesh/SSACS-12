## 1. What is a Module?
A **Module** is a file containing Python definitions and statements (functions, variables, classes). A **Library** is a collection of modules. Using modules allows us to reuse code without rewriting it.

### Ways to Import
1.  **Generic Import:** `import math`
    *   *Usage:* `math.sqrt(16)`
2.  **Specific Import:** `from math import sqrt`
    *   *Usage:* `sqrt(16)` (No need for the module name prefix)
3.  **Aliased Import:** `import math as m`
    *   *Usage:* `m.sqrt(16)`

---

## 2. The `math` Module
The `math` module provides mathematical functions for floating-point numbers.

| Function | Description | Example | Result |
|---|---|---|---|
| `math.ceil(x)` | Smallest integer >= x | `math.ceil(4.1)` | `5` |
| `math.floor(x)` | Largest integer <= x | `math.floor(4.9)` | `4` |
| `math.fabs(x)` | Absolute value (always float) | `math.fabs(-5)` | `5.0` |
| `math.pow(x, y)` | x raised to power y | `math.pow(2, 3)` | `8.0` |
| `math.sqrt(x)` | Square root | `math.sqrt(16)` | `4.0` |
| `math.pi` | The value of Pi (Constant) | `math.pi` | `3.1415...` |

## 3. The `random` Module
This is a high-weightage topic in the CBSE board exam.

1.  **`random.random()`**: Returns a random float between `0.0` and `1.0` (1.0 is excluded).
2.  **`random.randint(a, b)`**: Returns a random integer between `a` and `b` (**both inclusive**).
3.  **`random.randrange(start, stop, step)`**: Returns a random element from the range. The `stop` value is **exclusive**.

### The "Predict Output" Strategy
When you see a `randint(L, U)` question:
1.  Identify the **Minimum** and **Maximum** possible values.
2.  List all possible outputs by running the code for each value in that range.

---

## 4. The `statistics` Module
Used for mathematical statistics of numeric data.

1.  **`statistics.mean(data)`**: Arithmetic mean (average).
2.  **`statistics.median(data)`**: Middle value of data.
3.  **`statistics.mode(data)`**: Most common data point.

---

## CBSE Board Tips
- **Inclusive vs Exclusive:** Remember `randint` is inclusive on both sides, while `randrange` and `random` are exclusive on the upper bound.
- **Data Types:** `math.sqrt` and `math.pow` always return a **float**.
- **Namespace:** Never name your own script the same as a module (e.g., don't name your file `math.py`).
