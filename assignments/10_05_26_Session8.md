
### Task 3: Void vs Fruitful

2. Write a function `greet_f(name)` that **returns** "Hello" + name.
3. Run this:
   ```python
   x = greet_v("Mahissh")
   y = greet_f("Mahissh")

   print("y is:", y)
   ```
