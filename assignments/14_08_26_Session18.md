**Q4. Divisible by 5 Filter Stack: (5 Marks)**

### Tier 3: Logic & Edge Cases (10 Marks)

**Q5. Fixed-Size Stack & Overflow: (5 Marks)**
In theory, memory is finite. Write a Python function `push_limited(stack, item, max_size)` that pushes the `item` to the `stack` only if the size of the stack is strictly less than `max_size`. If the stack size has reached `max_size`, print `"Stack Overflow! Cannot push."` and do not modify the stack.

**Q6. Word Reversal using Stack: (5 Marks)**
Write a Python function `reverse_word(word)` that uses a stack (Python list) to reverse and return the characters of a string. Push all characters of the word one by one onto the stack, and then reconstruct the reversed word by popping characters from the stack.
