# Session 8: Functions Deep Dive — Arguments & Returns

In this session, we move from just "defining" functions to making them flexible using different types of arguments and learning how to get data "out" of a function using `return`.

---

## 1. Parameters vs. Arguments
Many people use these terms interchangeably, but they are different:
- **Parameters:** The variables you define in the function header. (The "Slots").
- **Arguments:** The actual values you send to the function during a call. (The "Fillers").

```python
def add(a, b): # a and b are parameters
    print(a + b)

add(10, 20)    # 10 and 20 are arguments
```

---

## 2. Types of Arguments

### A. Positional Arguments
The most common type. The values are assigned to parameters based on their **position/order**.
```python
def display(name, age):
    print(name, "is", age, "years old")

display("Mahissh", 17) # Correct
display(17, "Mahissh") # Logic Error! (17 is name, Mahissh is age)
```

### B. Default Arguments
You can provide "default" values to parameters. If the caller doesn't provide an argument, the default is used.
```python
def greet(name, msg="Welcome"):
    print("Hello", name, msg)

greet("Mahissh")                # Output: Hello Mahissh Welcome
greet("Mahissh", "Good Morning") # Output: Hello Mahissh Good Morning
```
**⚠️ Rule:** Default parameters **must** come at the end. 
`def func(a=10, b):` is a **Syntax Error**.

### C. Keyword Arguments
You can specify which value goes to which parameter by name. This allows you to ignore the order.
```python
display(age=17, name="Mahissh") # Works perfectly!
```

---

## 3. The `return` Statement
Until now, we used `print()` inside functions. But `print()` only shows a value on the screen. It doesn't allow the rest of the program to "use" that value.

- **`return`** sends a value back to the place where the function was called.
- A function **stops** immediately once it hits a `return`.

```python
def square(n):
    return n * n

result = square(5) # The value 25 is 'returned' and stored in 'result'
print(result + 10) # We can now use it! Output: 35
```

---

## 4. Returning Multiple Values
Python has a unique feature: a function can return more than one value! It packs them into a **Tuple**.

```python
def get_name_and_age():
    return "Mahissh", 17

info = get_name_and_age()
print(info) # Output: ('Mahissh', 17) - A Tuple!

# You can also "unpack" them immediately:
name, age = get_name_and_age()
print(name) # Mahissh
print(age)  # 17
```

## 5. Summary Table
| Argument Type | Order Matters? | Value required? |
|---|---|---|
| Positional | Yes | Yes |
| Default | Yes | No (uses default) |
| Keyword | No | Yes |
