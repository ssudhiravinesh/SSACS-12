# Session 7: Dictionaries & Introduction to Functions

## 1. Dictionaries (The "Encyclopedia")
A dictionary is a collection of **Key-Value** pairs. It is unordered (in older Python), mutable, and indexed by keys.

### Key Rules:
1.  **Unique Keys:** You cannot have two identical keys. If you try, the second one overwrites the first.
2.  **Immutable Keys:** Keys must be of a type that cannot change (e.g., String, Number, Tuple). Lists cannot be keys!
3.  **Values:** Can be anything (Lists, other Dictionaries, etc.).

### Common Operations:
```python
# Creation
student = {"name": "Mahissh", "grade": 12, "subject": "CS"}

# Access (The safe way)
print(student.get("name"))       # Returns "Mahissh"
print(student.get("age", "N/A")) # Returns "N/A" instead of crashing

# Adding/Updating
student["age"] = 17              # Adds new key
student["grade"] = "12th"        # Updates existing key

# Deleting
del student["subject"]
age = student.pop("age")         # Removes and returns the value

# Iterating
for key in student.keys():
    print(key)

for val in student.values():
    print(val)

for k, v in student.items():
    print(k, "->", v)
```

## 2. Introduction to Functions
A function is a reusable block of code that performs a specific task.

### Why use them?
- **Avoid Repetition:** Write once, use many times.
- **Organization:** Break a big problem into smaller "chunks".

### Defining vs Calling:
```python
# 1. Defining (The Recipe)
def welcome():
    print("Welcome to Python Functions!")

# 2. Calling (Cooking the Dish)
welcome()
```

### Flow of Execution:
Python reads code from top to bottom, but it **jumps** when it sees a function call.
1.  It skips the `def` block (just remembers the name).
2.  When the function is called, it jumps to the first line inside the `def`.
3.  After finishing the function, it jumps back to where it left off.

### Parameters vs Arguments:
- **Parameter:** The variable name in the function definition (the "slot").
- **Argument:** The actual value passed during the call (the "data").

```python
def greet(name): # 'name' is a parameter
    print("Hello", name)

greet("Mahissh") # "Mahissh" is an argument
```

---

## Key Takeaways:
- Use `.get()` for dictionaries to prevent `KeyError` crashes.
- Functions must be defined **before** they are called.
- Trace the flow of execution carefully—don't just read line by line!
