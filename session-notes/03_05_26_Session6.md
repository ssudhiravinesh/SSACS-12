# Session 6: Tuples, Dictionaries & Modules

## 1. Tuples
A tuple is an **immutable** sequence of values. Once created, you cannot change its elements.

### Key Features:
*   **Notation:** Defined using parentheses `()`.
*   **Single Element:** MUST have a trailing comma. `t = (5,)` is a tuple, but `t = (5)` is just an integer.
*   **Unpacking:** Assigning tuple elements to multiple variables in one line.
    ```python
    coords = (12.5, 30.1)
    lat, long = coords
    ```

### Important Functions:
*   `len(t)`: Number of elements.
*   `max(t)`, `min(t)`, `sum(t)`: Standard math functions.
*   `t.count(value)`: How many times a value appears.
*   `t.index(value)`: Position of the first occurrence.

---

## 2. Dictionaries
A dictionary is a collection of **Key-Value pairs**. It is unordered (in older Python) but optimized for fast lookups.

### Rules for Keys:
1.  Keys must be **Unique**.
2.  Keys must be **Immutable** (Strings, Numbers, or Tuples). You cannot use a List as a key.

### Common Operations:
*   `d['key']`: Access value (Error if key missing).
*   `d.get('key', default)`: Safely access value (Returns default if missing).
*   `d.keys()`: List of all keys.
*   `d.values()`: List of all values.
*   `d.items()`: List of (key, value) tuples.
*   `d.update(other_dict)`: Merges another dictionary into the current one.

---

## 3. Python Modules
Modules allow you to use pre-written code for complex tasks.

### math Module
*   `math.ceil(x)`: Rounds up.
*   `math.floor(x)`: Rounds down.
*   `math.pow(x, y)`: Returns x raised to y (as a float).
*   `math.sqrt(x)`: Square root.

### random Module (Important for Exams)
*   `random.random()`: Returns a float between 0.0 and 1.0.
*   `random.randint(a, b)`: Returns an integer between a and b **(Both a and b are included)**.
*   `random.randrange(start, stop)`: Returns an integer between start and stop **(Stop is NOT included)**.

### statistics Module
*   `statistics.mean(data)`: Average.
*   `statistics.median(data)`: Middle value.
*   `statistics.mode(data)`: Most frequent value.
