## 1. Introduction to Stack

A **Stack** is a linear data structure that follows the **LIFO (Last-In, First-Out)** principle. 

In a stack, elements are added and removed from only one end, called the **Top**. The other end of the stack is called the **Bottom**.

### Real-World Analogies:
* **Stack of Plates:** You can only place a new plate on the top of the pile, and you can only take the top plate off.
* **CD Holder:** You slide CDs into the holder from the top and take them out from the top.
* **Undo Mechanism (Ctrl+Z):** The most recent action you performed is the first one undone.

---

## 2. Core Terminology & Operations

1. **PUSH:** The operation of inserting or adding a new element onto the top of the stack.
2. **POP:** The operation of removing and returning the top element from the stack.
3. **PEEK / TOP:** Accessing or reading the top element without removing it.
4. **UNDERFLOW:** The error condition that occurs when you attempt to pop an element from an empty stack.
5. **OVERFLOW:** The error condition that occurs when you attempt to push an element onto a stack that has reached its maximum capacity.

---

## 3. List Representation of Stack in Python

In Python, a standard **list** is the most natural way to implement a stack.
* The end of the list (index `-1`) is treated as the **Top** of the stack.
* List method `.append()` is used for **PUSH**.
* List method `.pop()` is used for **POP**.

### Why do we use the end of the list as the Top?
Adding or removing elements from the end of a list in Python is very fast and efficient — it takes **constant time \(O(1)\)**. Inserting or removing from the beginning of the list requires shifting all other elements, which takes **linear time \(O(N)\)**.

---

## 4. Standard Python Implementation

Here is the clean, standard Python code used to implement stack operations. In CBSE examinations, you are expected to check for **underflow** in your `pop` function to avoid runtime errors.

```python
# 1. Initialize an empty stack
my_stack = []

# 2. Push Function
def push_item(stack, item):
    stack.append(item)
    print(f"Pushed element: {item}")

# 3. Pop Function (with Underflow Check)
def pop_item(stack):
    # Underflow check: must verify if stack is empty first!
    if len(stack) == 0:
        print("Stack Underflow! The stack is empty.")
        return None
    else:
        popped_value = stack.pop()
        return popped_value

# 4. Peek Function
def peek_item(stack):
    if len(stack) == 0:
        print("Stack is empty.")
        return None
    else:
        return stack[-1]
```

### Demonstration:
```python
push_item(my_stack, "A")
push_item(my_stack, "B")
print("Top item:", peek_item(my_stack)) # Output: B
print("Popped:", pop_item(my_stack))    # Output: B
print("Popped:", pop_item(my_stack))    # Output: A
print("Popped:", pop_item(my_stack))    # Prints Stack Underflow message
```

## 5. Visualizing Stack State Transitions

Suppose we execute this sequence of operations on an empty stack:
1. `push_item(stk, 5)`
2. `push_item(stk, 10)`
3. `pop_item(stk)`
4. `push_item(stk, 15)`

Here is how the stack changes:

```
[Initial]    [Push 5]    [Push 10]    [Pop]       [Push 15]
  |   |        |   |      |  10 |     |   |        |  15 |  <-- Top
  |   |        | 5 |      |  5  |     | 5 |        |  5  |
  +---+        +---+      +-----+     +---+        +-----+
```
* Note how the list state after Step 4 is `[5, 15]`.
